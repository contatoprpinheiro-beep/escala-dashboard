# Escala Dashboard — Escala Report v3.0

Estrutura preparada para clientes da Escala Ecom.

## Estrutura

- `index.html`: central de clientes
- `clientes/lc-lux/index.html`: relatório executivo LC LUX
- `clientes/lc-lux/dados.json`: base editável do cliente
- `assets/img/escala-logo.png`: logo global da Escala Ecom
